01. about

A full-stack developer moving into AI

I'm a Software Developer based in Mumbai with over two and a half years of experience designing, building, and maintaining scalable web applications. My day-to-day work centers on the .NET ecosystem — C#, ASP.NET, ASP.NET Core, MVC — paired with Angular on the front end and MS SQL Server for data.

Beyond feature work, I care about the things that make software trustworthy: resolving performance issues and security vulnerabilities, and applying OWASP best practices to keep systems stable, secure, and compliant.

Over the last year I've been pulling AI/ML into that toolkit — building a RAG-powered chatbot with Python and LLMs and wiring it into an ASP.NET application via REST APIs, alongside personal projects in computer vision and predictive modelling. I'm an adaptable, continuous learner, and I'm most interested in the overlap between dependable backend engineering and intelligent, data-driven features.
